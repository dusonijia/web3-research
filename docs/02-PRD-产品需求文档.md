## 1. 产品概述

GreenPulse 是面向新能源行业的 AI 驱动情报平台，通过智能体自动采集全球专利、论文和新闻数据，提供实时可视化、深度分析和投资建议。

### 1.1 产品定位

**一句话定位**: 全球新能源领域的 AI 实时情报中枢

### 1.2 核心价值主张

- **全**: 覆盖 47 个国家、128,000+ 专利、56,000+ 论文
- **快**: AI 智能体 7×24h 实时监控，分钟级更新
- **深**: GPT-4o 驱动的深度技术分析和投资建议
- **准**: 多数据源交叉验证，准确率 > 97%

## 3. 功能详细描述

### 3.1 全球动态地图

**优先级**: P0  
**用户故事**: 作为行业分析师，我希望在世界地图上直观看到全球新能源活动热点，以快速把握行业动态。

#### 功能描述

| 子功能 | 描述 |
|--------|------|
| 真实世界地图 | 基于 Leaflet + CartoDB 暗色瓦片的交互式地图 |
| 事件标记 | 脉冲动画圆点标记，颜色区分类型，大小映射影响力 |
| 类型筛选 | 全部 / 专利 / 论文 / 新闻 / 电池 五个过滤器 |
| 弹窗详情 | 鼠标悬浮显示事件标题、类型和影响力评分 |
| 图例说明 | 右下角固定图例：黄色=专利、蓝色=论文、绿色=新闻、红色=突破 |
| 缩放导航 | 支持滚轮缩放、拖拽平移、最小缩放级别=2 |

#### 颜色编码

| 事件类型 | 颜色 | 色值 |
|---------|------|------|
| 专利 | 金色 | #ffd600 |
| 论文 | 蓝色 | #00b0ff |
| 新闻 | 绿色 | #00c853 |
| 重大突破 | 红色 | #ff5252 |

#### 数据来源

- 18 个全球城市的实时事件数据
- 每个事件包含: 经纬度、类型、标签、影响力(0-100)

---

### 3.2 每日动态信息流

**优先级**: P0  

#### 功能描述

地图下方的卡片网格，展示最新的专利、论文、新闻和报告动态。

| 字段 | 描述 |
|------|------|
| 类型标签 | 彩色标签(专利/论文/新闻/报告) |
| 时间 | 相对时间(x小时前) |
| 国家 | 国旗emoji + 国家名 |
| 标题 | 事件标题，最多2行 |
| 摘要 | 事件描述，最多2行 |
| 来源 | 数据来源机构 |
| 影响力 | 高/中/低，颜色区分 |
| 点击 | 打开对应的详情页面 |

---

### 3.3 前沿技术排名

**优先级**: P0  

#### 功能描述

六大领域的技术和企业双排名系统。

**六大领域标签页**:
- 🔋 电池技术
- ☀️ 太阳能
- 💧 氢能
- 🌬️ 风能
- ⚡ 储能
- 🚗 电动汽车

**双栏排名**:

| 栏目 | 内容 |
|------|------|
| 🔬 技术排名 | Top 5技术及AI综合评分 |
| 🏢 企业排名 | Top 5企业及AI综合评分 |

**排名项字段**: 排名序号(金银铜)、名称、详情、评分(0-100)、变化趋势(↑/↓)

**交互**: 点击技术项打开技术详情页，点击企业项打开企业详情页。

### 3.4 核心论文研读

**优先级**: P0  

#### 论文卡片字段

| 字段 | 描述 |
|------|------|
| 期刊名称 | 如 Nature Energy、Science |
| 发表日期 | YYYY-MM-DD |
| 论文标题 | 英文标题 |
| 中文摘要 | AI翻译的中文摘要 |
| 技术标签 | 如固态电池、锂金属 |
| AI研读标记 | 🤖标识已有AI深度分析 |
| 作者 | 前5位作者 |
| 引用/下载 | 引用次数和下载次数 |

#### 论文详情页

点击论文卡片打开全屏详情面板：

- 顶部元信息: 期刊、日期、作者、分类
- 关键指标: 引用数、下载数、期刊名
- 技术标签列表
- 完整摘要
- **AI 深度研读报告**: 核心发现、性能参数表、产业化影响、局限性、投资启示

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|------|------|
| 首页加载时间 | < 3秒 |
| API 响应时间 | < 500ms (P95) |
| 地图渲染时间 | < 2秒 |
| 详情页打开时间 | < 300ms |
| 并发用户 | 支持 1000+ |

### 4.2 响应式设计

| 断点 | 设备 | 布局 |
|------|------|------|
| > 1200px | 桌面 | 多列网格 |
| 768-1200px | 平板 | 双列 → 单列 |
| < 768px | 手机 | 单列，汉堡菜单 |
| < 480px | 小屏手机 | 紧凑布局 |

### 4.3 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
- 移动端 Chrome/Safari

### 4.4 安全性

- HTTPS 加密传输
- API 输入验证 (Pydantic)
- CORS 跨域控制
- 环境变量管理敏感信息

## 5. 详情页交互规范

### 5.1 打开方式

所有详情页通过点击首页卡片触发，以全屏覆盖层(Overlay)形式展示。

### 5.2 关闭方式

- 点击右上角 × 按钮
- 点击覆盖层背景（灰色遮罩区域）
- 按 Escape 键

### 5.3 动画

- 打开: slideUp 动画 (0.3s ease)
- 关闭: 立即隐藏
- 覆盖层: 背景模糊 4px

### 5.4 移动端适配

- 详情面板在 < 768px 时全屏显示（无圆角）
- 内容区域缩小 padding
- 指标网格适配为 2 列或 1 列
