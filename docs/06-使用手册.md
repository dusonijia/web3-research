## 1. 平台简介

GreenPulse 是全球领先的新能源情报监控与分析平台。基于 6 个 AI 智能体，7×24 小时不间断监控全球 47 个国家的新能源专利、学术论文和产业新闻，特别聚焦电池技术领域。

### 1.1 平台能做什么

- 在全球地图上实时查看新能源活动热点
- 了解六大新能源领域的技术和企业排名
- 阅读 AI 深度解读的核心论文和专利
- 查看企业全景分析报告
- 获取 AI 投资建议和机会评估
- 下载自动生成的产业布局报告

### 1.2 访问方式

**方式一**: 直接打开 HTML 文件

```
双击打开 frontend/index.html 即可查看完整界面
```

**方式二**: 通过后端服务访问

```
启动服务后访问 http://localhost:8000
```

## 3. 功能详细使用

### 3.1 全球动态地图

#### 查看地图

地图显示全球新能源活动热点，每个圆点代表一个事件：

| 圆点颜色 | 含义 |
|---------|------|
| 🟡 金色 | 专利申请/授权 |
| 🔵 蓝色 | 论文发表 |
| 🟢 绿色 | 产业新闻 |
| 🔴 红色 | 重大突破 |

圆点大小反映事件的影响力评分（越大影响越大）。

#### 操作方法

| 操作 | 方法 |
|------|------|
| 放大/缩小 | 滚轮 或 左下角 +/- 按钮 |
| 平移 | 拖拽地图 |
| 查看详情 | 点击圆点，弹出事件信息 |
| 类型筛选 | 点击左上角过滤按钮 |

#### 过滤器

左上角有 5 个过滤按钮：

- **全部**: 显示所有事件
- **专利**: 仅显示专利相关事件
- **论文**: 仅显示论文相关事件
- **新闻**: 仅显示新闻事件
- **电池**: 高亮电池相关的专利和论文

#### 每日动态卡片

地图下方显示最新的动态信息流，每张卡片包含：

- 类型标签（彩色）+ 发布时间 + 国家
- 事件标题和简要描述
- 数据来源和影响力等级

**点击任意卡片即可查看完整详情**。

---

### 3.2 前沿技术排名

#### 切换领域

顶部有 6 个标签页，点击切换领域：
- 🔋 电池技术 | ☀️ 太阳能 | 💧 氢能 | 🌬️ 风能 | ⚡ 储能 | 🚗 电动汽车

#### 查看排名

每个领域显示两个排名面板：

- **左侧 - 🔬 技术排名**: 该领域 Top 5 技术方向
- **右侧 - 🏢 企业排名**: 该领域 Top 5 企业

每个排名项显示：
- 排名序号（金🥇银🥈铜🥉色）
- 技术/企业名称
- AI 综合评分（0-100）
- 周变化趋势（↑/↓）

#### 查看详情

- **点击技术项** → 打开技术详情页（能量密度、TRL、量产预测、深度分析）
- **点击企业项** → 打开企业详情页（市值、市占率、技术路线图、投资评级）

---

### 3.3 核心论文研读

#### 浏览论文

论文以卡片网格形式展示，每张包含：

- 期刊名称（Nature Energy / Science / Joule 等）
- 发表日期
- 论文标题（英文）
- 中文摘要
- 技术标签
- 🤖 AI研读 标记（表示已有深度分析）
- 作者、引用数、下载数

#### 分类筛选

顶部标签可筛选论文类型：
全部 | 固态电池 | 锂离子电池 | 钠离子电池 | 钙钛矿 | 氢燃料电池

#### 阅读论文详情

**点击任意论文卡片**，打开详情面板，包含：

1. **元信息**: 期刊、日期、作者、分类
2. **关键指标**: 引用数、下载数
3. **技术标签**: 相关技术关键词
4. **完整摘要**: 中文翻译摘要
5. **AI 深度研读报告**:
   - 核心发现与创新点
   - 性能参数对比表
   - 产业化影响评估
   - 研究局限性
   - 投资启示

---

### 3.4 核心专利研读

#### 浏览专利

专利卡片展示：
- 专利号（等宽字体）
- 状态: ✅已授权 / ⏳审查中 / 📢已公开
- 标题
- 摘要
- 专利权人（Logo + 名称）
- 国家和日期

#### 阅读专利详情

**点击任意专利卡片**，打开详情面板，包含：

1. **专利号和状态**
2. **关键信息**: 专利权人、国家、技术领域
3. **完整摘要**
4. **AI 专利深度解读**:
   - 技术创新点（3-5个）
   - 权利要求分析
   - 产业影响评估
   - 竞争格局分析

---

### 3.5 企业详情页

从技术排名中点击企业名称进入。

页面包含：
- **基本信息**: 国家、股票代码、市值、创立年份
- **关键指标**: 市占率、装机量、研发投入、专利数量、员工数
- **技术路线图**: 详细的技术布局分析
- **财务概况**: 营收、利润等关键数据
- **近期核心专利**: 最新重要专利列表
- **投资评级**: 买入/持有/卖出 + 分析师点评

---

### 3.6 投资建议

投资建议板块展示 AI 分析的投资机会：

#### 投资卡片

每张卡片包含：
- **评级**: 强烈推荐（红色）/ 推荐（黄色）
- **时间框架**: 短期/中期/长期
- **投资主题**: 如"固态电池产业链投资机会"
- **核心逻辑**: 一句话投资理由
- **机会列表**: Top 3 投资机会（名称 + 潜力 + 风险）
- **关注企业**: 相关企业标签

#### 查看详细分析

**点击投资卡片**打开详情，包含：
- 完整投资机会清单
- 每个机会的潜力和风险评估
- 重点关注企业列表
- AI 分析师的详细投资论述
- 风险提示

---

### 3.7 产业布局报告

报告以封面卡片形式展示：
- 报告类型标签（深度报告/竞争分析/产业白皮书等）
- 渐变色封面 + 主题emoji
- 标题和摘要
- 发布日期和页数

**点击报告卡片**可预览报告信息。完整报告由 AI 智能体自动生成。

### 3.8 AI 智能体面板

展示 6 个 AI 智能体的实时运行状态：

| 智能体 | 功能 | 监控内容 |
|--------|------|---------|
| 📋 专利监控 | 全球专利抓取 | USPTO/EPO/CNIPA/JPO/KIPO |
| 📄 论文追踪 | 学术论文追踪 | Nature/Science/Joule/arXiv |
| 📰 新闻采集 | 行业新闻采集 | Reuters/Bloomberg/新华社 |
| 🔋 电池专项 | 电池深度分析 | 综合专利+论文+新闻 |
| 📊 报告生成 | 自动写报告 | 全数据源 |
| 🌐 翻译摘要 | 多语言翻译 | 中/英/日/韩/德 |

每个智能体显示：
- 运行状态（绿色脉冲 = 运行中）
- 今日处理量
- 累计处理量
- 最近活动描述

## 4. 详情页操作

### 4.1 打开详情

点击任何可点击的卡片或排名项，详情页会以覆盖层形式打开。

### 4.2 关闭详情

三种方式：
1. 点击右上角 **×** 按钮
2. 点击灰色背景区域
3. 按键盘 **Esc** 键

### 4.3 详情页内容

所有详情页遵循统一布局：
- 顶部: 元信息标签（彩色小标签）
- 标题: 大号粗体
- 关键指标: 数据面板
- 标签: 技术关键词
- 正文: AI分析内容（支持标题、列表、表格、粗体）

## 6. 部署和配置

### 6.1 直接查看前端

```bash
# 无需任何安装，直接打开HTML
open frontend/index.html
# 或在浏览器地址栏输入文件路径
```

### 6.2 启动完整服务

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 OpenAI API Key (可选)

# 2. 启动服务
./scripts/run-local.sh

# 3. 访问
http://localhost:8000
```

### 6.3 Docker 部署

```bash
cd deployment/docker
export OPENAI_API_KEY=sk-your-key  # 可选
docker-compose up -d --build
# 访问 http://localhost:8000
```

### 6.4 AWS 一键部署

```bash
export AWS_REGION=us-east-1
export KEY_PAIR_NAME=your-keypair
./scripts/deploy-aws.sh
# 按提示操作，3-5分钟后自动完成
```

## 7. API 使用指南

平台提供 RESTful API 供程序调用：

### 7.1 基础地址

```
http://localhost:8000/api/v1
```

### 7.2 常用接口

| 接口 | 用途 | 示例 |
|------|------|------|
| `/health` | 检查服务状态 | `curl /api/v1/health` |

| `/patents` | 获取专利列表 | `curl /api/v1/patents?category=battery` |
| `/papers` | 获取论文列表 | `curl /api/v1/papers?category=solar` |

## 8. 常见问题 (FAQ)

### Q: 前端页面打开后没有地图？

A: 地图需要网络连接来加载 CartoDB 瓦片。请确保可以访问 `basemaps.cartocdn.com`。

### Q: AI 分析内容从哪里来？

A: 当前版本使用预生成的 AI 分析内容。启动后端服务并配置 `OPENAI_API_KEY` 后，智能体会自动调用 GPT-4o 生成新的分析。

### Q: 如何添加自定义监控关键词？

A: 当前版本的关键词配置在各 Agent 源码中（如 `patent_agent.py` 的 `PATENT_KEYWORDS`）。后续版本将支持通过界面自定义。

### Q: 数据多久更新一次？

A: 各智能体按不同频率更新：
- 新闻: 每 30 分钟
- 专利: 每 60 分钟
- 论文: 每 120 分钟
- 报告: 每 24 小时

### Q: 支持哪些浏览器？

A: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+，以及移动端 Chrome 和 Safari。
