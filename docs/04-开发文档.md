| 组件 | 最低版本 |

### 1.2 快速启动

```bash
# 克隆仓库
git clone https://github.com/your-org/greenpulse.git
cd greenpulse

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API Keys

# 本地运行
./scripts/run-local.sh
```

| 变量 | 必填 | 默认值 | 说明 |

## 3. 前端开发指南

### 3.1 架构说明

前端采用零框架依赖的纯 HTML/CSS/JS 方案，通过 CDN 引入 Leaflet 地图库。所有页面在单个 `index.html` 中实现。

### 3.2 数据流

```
GP_DATA (data.js)
    │
    ├── renderDailyFeed()     → #dailyFeed
    ├── renderRankings(cat)   → #rankingsGrid
    ├── renderPapers()        → #papersGrid
    ├── renderPatents()       → #patentsGrid
    ├── renderInvestments()   → #investmentsGrid
    ├── renderReports()       → #reportsGrid
    ├── renderAgents()        → #agentGrid
    └── GreenPulseMap.init()  → #worldMap (Leaflet)
```

### 3.3 详情页路由系统

所有详情页使用 Overlay 模式，通过 `openDetail(html)` / `closeDetail()` 管理：

```javascript
// 打开详情
function openDetail(html) {
  document.getElementById("detailContent").innerHTML = html;
  document.getElementById("detailOverlay").classList.add("open");
  document.body.style.overflow = "hidden";
}

// 关闭详情
function closeDetail() {
  document.getElementById("detailOverlay").classList.remove("open");
  document.body.style.overflow = "";
}
```

**详情页入口函数**:

| 函数 | 触发元素 | 数据来源 |
|------|---------|---------|
| `openPaperDetail(id)` | 论文卡片 | `GP_DATA.papers` |
| `openPatentDetail(id)` | 专利卡片 | `GP_DATA.patents` |
| `openNewsDetail(id)` | 新闻卡片 | `GP_DATA.news` |
| `openTechDetail(id)` | 技术排名项 | `GP_DATA.techDetails` |
| `openCompanyDetail(id)` | 企业排名项 | `GP_DATA.companyDetails` |
| `openInvestDetail(id)` | 投资卡片 | `GP_DATA.investments` |
| `openReportDetail(id)` | 报告卡片 | `GP_DATA.reports` |

### 3.4 地图模块

```javascript
const GreenPulseMap = (() => {
  // Leaflet 地图实例
  let map = null;

  function init(containerId, events) {
    // 1. 初始化 Leaflet 地图

    L.tileLayer("https://{s}.basemaps.cartocdn.com/dark_nolabels/...");
    L.tileLayer("https://{s}.basemaps.cartocdn.com/dark_only_labels/...");

    // 3. 添加脉冲标记点
    addEvents(events);
  }

  function filter(containerId, type) {
    // 按类型过滤标记的显示/隐藏
  }

  return { init, filter };
})();
```

### 3.5 Markdown 渲染

`mdToHtml(md)` 函数实现简化的 Markdown 到 HTML 转换：

- `# / ## / ###` → `<h1> / <h2> / <h3>`
- `**bold**` → `<strong>`
- `- list` → `<ul><li>`
- `| table |` → `<table>`
- 段落分隔 → `<p>`

## 4. 后端开发指南

### 4.1 FastAPI 应用初始化

```python
# backend/main.py
@asynccontextmanager
async def lifespan(app: FastAPI):
    await init_db()           # 创建数据库表
    if settings.OPENAI_API_KEY:
        start_scheduler()      # 启动AI智能体
    yield

app = FastAPI(title="GreenPulse", lifespan=lifespan)
app.add_middleware(CORSMiddleware, ...)
app.include_router(router)
app.mount("/", StaticFiles(directory=frontend_dir, html=True))
```

### 4.2 添加新 API 端点

```python
# 1. 在 schemas.py 定义 Pydantic 模型
class NewFeature(BaseModel):
    id: str
    name: str

# 2. 在 data_service.py 实现数据逻辑
def get_new_features() -> list[NewFeature]:
    return [...]

# 3. 在 routes.py 注册端点
@router.get("/new-features", response_model=list[NewFeature])
async def new_features():
    return get_new_features()
```

# 1. 继承 BaseAgent
class MyAgent(BaseAgent):

## 5. 部署指南

### 5.1 Docker 部署

```bash
cd deployment/docker
export OPENAI_API_KEY=sk-your-key
docker-compose up -d --build

# 查看日志
docker-compose logs -f

# 停止
docker-compose down
```

### 5.2 AWS 一键部署

```bash
# 前置条件
aws configure  # 设置AWS凭证

# 部署
export KEY_PAIR_NAME=my-keypair
export OPENAI_API_KEY=sk-your-key
./scripts/deploy-aws.sh
```

CloudFormation 创建以下资源:
- VPC + 公网子网
- Internet Gateway + 路由表
- 安全组 (22/80/443/8000)
- EC2 实例 (UserData 自动安装 Docker + Nginx)

### 5.3 手动服务器部署

```bash
# Ubuntu 22.04 服务器
sudo apt update && sudo apt install -y python3.12 python3.12-venv git nginx

git clone https://github.com/your-org/greenpulse.git /opt/greenpulse
cd /opt/greenpulse

python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 生产运行
export PYTHONPATH=/opt/greenpulse
gunicorn backend.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

## 6. 编码规范

### 6.1 Python 规范

- 遵循 PEP 8
- 使用 `from __future__ import annotations` 延迟类型求值
- 异步函数使用 `async/await`
- 类型注解所有函数签名
- 日志使用 `logging` 模块

### 6.2 前端规范

- CSS 使用 CSS 变量(Custom Properties)管理主题
- JavaScript 使用原生 DOM API，不引入框架
- 函数命名: `renderXxx()` 用于渲染, `openXxxDetail()` 用于打开详情
- 数据统一存储在 `GP_DATA` 对象中

### 6.3 Git 规范

```
feat: 新功能
fix: 修复Bug
docs: 文档更新
style: 样式调整
refactor: 重构
test: 测试
deploy: 部署
```
